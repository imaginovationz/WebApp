How each step is satisfied

1. UI with dropdowns + Go button → ALMRunner.jsx page (new).

2. Connect to ALM with OTA + config → /api/alm/connect in almapp.py calls 
your existing DQLConnector (which reads keys/URL from read_config.py → config.json). 
Nothing to re-enter in code; just populate your keys in the JSON. 

3. Run query from /dql/*.sql → /api/alm/run_dql loads a file like ALM_connection.sql, 
replaces <DB_NAME> and <SelectedReleaseID> when present, then executes via OTA (exactly how your existing app.py flow works). 

4. Render Power BI dynamically → PBReactUI.js supports both quick iframe and (optional) SDK-based dynamic filters. 
The React page passes reportData derived from the rows so you can map it to slicers/filters.
